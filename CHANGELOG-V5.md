# StorySiap v5 — Immersive Continuous Motion

- Fixed hero split-color issue: one continuous dark cinematic backdrop on all viewports, including nav and responsive layout.
- Added scroll-linked pinned cinematic story chapter with three states, smooth interpolated 3D elements and photographic layers.
- Added deterministic responsive canvas particles, animated atmospheric glow, cursor lighting and scroll-linked transforms.
- Improved hero typography, navigation color and tonal continuity into the next section.
- Preserved all photo/video Studio features, auto-scroll controls, performance fallbacks and accessibility preferences.
- No third-party CDN runtime added; designed for offline localhost testing.

## Preview / deployment
Run `BUKA-STORYSIAP.bat` in Windows. For an external URL publish the `story-siap/dist` directory with a static host. ChatGPT Work's Cloud Browser can be used in Work mode for browser-based review; localhost on the user's computer is not accessible to other devices.
